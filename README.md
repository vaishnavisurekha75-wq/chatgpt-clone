# 🤖 ChatGPT Clone

A modern AI-powered chatbot application inspired by ChatGPT, built with React, Node.js, Express.js, and Google Gemini AI.

Users can enter questions or messages and receive AI-generated responses through a simple and interactive chat interface.

## ✨ Features

- 💬 Real-time AI chat interface
- 🤖 Google Gemini AI integration
- 🧠 AI-generated responses
- 📱 Responsive and user-friendly UI
- ⚡ Fast React frontend
- 🔗 React frontend connected with Node.js backend
- 🔐 Environment variable support for API keys
- 🌐 Backend API using Express.js
- 🔄 Dynamic chat interaction
- 🎨 Clean and modern ChatGPT-style interface

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Node.js
- Express.js
- Google Gemini AI
- REST API
- Git & GitHub
- Vercel / Render
